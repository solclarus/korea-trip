# ソウル旅行 2026 振り返り

2026/10/15〜17 のソウル2泊3日を、地図・タイムライン・支出で振り返るアプリ。

```sh
npm install
npm run dev     # http://localhost:5173
npm run build   # 型チェック + ビルド
npm run paths   # 移動経路（線路・道路沿い）を生成
```

## 技術構成

Vite 8 / React 19 / TypeScript 7 / Tailwind CSS 4 / shadcn/ui（Radix）/ Lucide アイコン。
地図は Leaflet ＋ MapLibre GL 6（OpenFreeMap のベクタータイル）。

- 画面の部品は `src/components/ui/`（shadcn/ui）。追加は `npx shadcn@latest add <名前>`
- 色・角丸などのテーマは `src/index.css` の CSS 変数。フォントはいまは OS 標準

## 写真

`public/photos/` に置いて、`src/data/trip.ts` の `photos` に追加する。
撮影日時（`at`）か場所（`placeId`）で、旅程の滞在に自動で入る。写真がなくても画面は成り立つ。

## できること

- **日程タブ**：全日程 / Day 1〜3 で地図・タイムライン・集計をまとめて切り替え
- **地図**：日ごとに色分けしたルート（徒歩は点線、飛行機は破線）と訪問順の番号ピン
- **再生**：スライダーか ▶ で、その時刻にどこにいたかを地図上で追う（夜間のホテル滞在は早送り）
- **タイムライン**：滞在・移動・そこで使ったお金を時系列で表示。クリックで地図が移動
- **支出**：カテゴリ別（クリックで明細を絞り込み）、日別の積み上げ、並べ替えできる明細
- **通貨切替**：円 / ウォン

## データ

データは `src/data/trip.ts` の1ファイルだけ（今はモック）。型は `src/types.ts` にある。

| 配列 | 中身 | 紐づけ |
|---|---|---|
| `places` | 地点（日本語・英語・韓国語の名前、緯度経度） | `id` |
| `visits` | 滞在（到着・出発時刻、メモ、満足度） | `placeId` |
| `moves` | 移動（手段、路線、任意で実経路 `path`） | `from` / `to` |
| `expenses` | 支出（金額・通貨・カテゴリ・支払方法） | `placeId` か `moveId` |

- 時刻は現地時刻の `"YYYY-MM-DDTHH:mm"`。日本と韓国はどちらも +09:00 なので変換は不要
- 移動経路は次の優先順で描く
  1. `moves[].path`：GPSログ（Googleマップのタイムラインなど）があればここに入れる
  2. `src/data/paths.generated.json`：`npm run paths` で生成した経路
  3. どちらも無ければ直線
- `npm run paths` で作る経路
  - 電車・地下鉄：`moves[].rail` に書いた路線（OSM の route relation の id）と乗車駅・降車駅（韓国語名）から、線路の形を切り出す
  - 徒歩：歩行者ルート、バス・タクシー：車のルート（OSRM）。バスは実際の路線ではなく道路沿いの近似
  - 取得結果は `.cache/` に保存されるので、データを変えたときだけネットワークに出る
- 支出がタイムラインに出るのは、`at` がその地点の滞在時間内にある場合だけ（明細には必ず出る）
- 為替レートは `fx`（1単位あたりの円）
